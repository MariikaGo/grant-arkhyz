## Ограничения и остаточные задачи

Изменения ещё не развёрнуты: существующий публичный сайт и его риски остаются до отдельно согласованного выпуска. Опубликованный старый пароль следует сменить в настройках работающей админки, если он применялся; удаление из нового коммита не удаляет историю. Не закрывать весь сайт ради админки.

Прежняя админка сохранена для обработки старых данных. Её Basic Auth не предоставляет MFA, учёт отдельных пользователей, аудит изменений или защиту от перебора. До внешнего запуска обязательны HTTPS и отдельный шлюз с MFA/IP-ограничением, rate limit. Не публиковать корень репозитория на обычном хостинге. БД и копии заявок не переносились; миграция и реальный CRUD с PostgreSQL в рамках этой проверки не проверены.

Нет подтверждённых фото готового дома, цены, вместимости каждого варианта и актуальных прямых контактов. Новый дизайн до их добавления — подготовленная версия для просмотра, не готовый к выпуску рекламный сайт. Подробности: CONTENT.md.

Автоматические проверки см. tests/: публичные страницы открыты, исходники закрыты, все административные методы защищены, неверный Origin отклоняется, отсутствие настройки не закрывает сайт, старая форма отключена, HTML экранируется, статическая сборка не включает админку. Итог выполнения и браузерной проверки фиксируется отдельно при завершении.
